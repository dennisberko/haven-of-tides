# Phase 43: Day and night

[Previous: Phase 42 - Relationship progress](42-relationship-progress.md) | [Next: Phase 44 - Fast travel](44-fast-travel.md)

## Goal

Make time change one activity at the cove.

## Add

- Add day and night states.
- Show the current state in the cove.
- Change the cove light and sky for each state.
- Advance the state after a voyage.
- Make one resident scene available only at night.
- Tell the player when the scene is not available.

## Use from earlier phases

- Cove walking
- Dialogue
- Voyages
- Resident reactions
- Relationship progress

## Complete when

A voyage can change day to night, and one resident scene follows the shown time rule.

## Do not add

- A calendar
- Seasons
- Detailed resident schedules
- Timed request failure
- Sleep needs
- Real-time waiting

## Test

1. Visit the resident during the day.
2. Confirm that the night scene is not available and that the reason is clear.
3. Complete one voyage and return at night.
4. Confirm that the cove appearance changed.
5. Talk to the resident and start the night scene.
