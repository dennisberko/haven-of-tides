# Phase 38: Story clues

[Previous: Phase 37 - Tool gates](37-tool-gates.md) | [Next: Phase 39 - Monster hunting](39-monster-hunting.md)

## Goal

Make one found object reveal the next story location.

## Add

- Add one map fragment in the ruin.
- Record the fragment in a simple clue list.
- Give the clue one short description.
- Mark one new location on the sea chart.
- Keep the clue after the player returns to the cove.

## Use from earlier phases

- Interaction
- Waypoints
- Cargo
- Ruin exploration
- Tool gates

## Complete when

The player finds the map fragment, sees its clue, and gets a clear new destination.

## Do not add

- Several clue chains
- Clue combination
- A deduction screen
- Cursed objects
- Resident reactions
- Relationship progress

## Test

1. Open the tool gate in the ruin.
2. Take the map fragment.
3. Confirm that the clue list gets one entry.
4. Open the sea chart and find the new location.
5. Return to the cove and load the saved game.
6. Confirm that the clue and location remain available.
