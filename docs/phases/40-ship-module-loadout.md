## Goal

Make the player choose ship equipment before a voyage.

## Add

- Add one ship module slot.
- Add cargo racks, long guns, and fishing gear.
- Let the player select one module at the cove.
- Make cargo racks add cargo space.
- Make long guns add one pursuit attack option.
- Make fishing gear allow one larger catch.
- Show the selected module in the ship view.

## Use from earlier phases

- Cove interaction
- Cargo limit
- Naval attack
- Sail damage
- Fishing
- Monster hunting

## Complete when

The player must choose cargo, combat, or fishing equipment. Each choice changes an action or an available opportunity on the next voyage.

## Do not add

- More module slots
- Module levels
- A large upgrade tree
- Passive percentage bonuses
- Ship cosmetics
- More owned ships

## Test

1. Select cargo racks and confirm the new cargo limit.
2. Return to the cove and select long guns.
3. Confirm that the pursuit attack is available and the extra cargo space is not.
4. Return and select fishing gear.
5. Confirm that the larger catch is available and the pursuit attack is not.
