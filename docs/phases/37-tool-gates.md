# Phase 37: Tool gates

[Previous: Phase 36 - Ruin exploration](36-ruin-exploration.md) | [Next: Phase 38 - Story clues](38-story-clues.md)

## Goal

Let one tool open a blocked path in a known ruin.

## Add

- Add one exploration tool.
- Add one blocked path in the existing ruin.
- Show the required tool at the blocked path.
- Keep the path closed when the player does not have the tool.
- Open the path when the player returns with the tool.
- Put one normal treasure behind the path.

## Use from earlier phases

- Interaction
- Resident requests
- Cargo
- Ruin exploration

## Complete when

The player sees the blocked path, gets the tool, returns, and opens the path.

## Do not add

- Tool upgrades
- Tool durability
- Several gate types
- Story clues
- A player skill tree
- Many required return visits

## Test

1. Enter the ruin without the tool.
2. Confirm that the path stays closed and shows the required tool.
3. Get the tool through the test request.
4. Return to the same path.
5. Open it and collect the treasure.
6. Confirm that the path stays open.
