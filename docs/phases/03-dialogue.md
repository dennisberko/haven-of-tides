# Phase 03: Dialogue

[Previous: interaction](02-interaction.md) | [Next: resident requests](04-resident-requests.md)

## Goal

The player can talk to one named resident.

## Add

- Place one named resident in the cove.
- Use the interaction button to start a short dialogue.
- Show the speaker name and one or more lines of text.
- Let the player advance the text and close the dialogue.
- Stop player movement while the dialogue is open.

## Use from earlier phases

- Walking
- Interaction range and prompt

## Complete when

The player can start, read, finish, and start the resident dialogue again without an input or movement error.

## Do not add

- Dialogue choices
- Requests
- Relationship points
- Resident schedules
- Different dialogue after events

## Test

1. Walk to the resident.
2. Start the dialogue.
3. Advance through every line.
4. Confirm that movement is off while the dialogue is open.
5. Close the dialogue, walk away, and talk to the resident again.
