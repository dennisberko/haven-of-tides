# Phase 04: Resident requests

[Previous: dialogue](03-dialogue.md) | [Next: enter and leave the ship](05-enter-and-leave-ship.md)

## Goal

The player can accept and complete one request from the resident.

## Add

- Give the resident one request with one clear goal.
- Let the player accept the request in dialogue.
- Show the active goal in a small request view.
- Mark the goal complete when the player visits the damaged dock.
- Let the player return to the resident to finish the request.

## Use from earlier phases

- Walking
- Interaction
- Dialogue

## Complete when

The player can accept the request, do its goal, return to the resident, and see that the request is complete.

## Do not add

- More than one request
- Time limits
- Request choices
- Cargo or item rewards
- Relationship progress
- A request log with categories or filters

## Test

1. Talk to the resident and accept the request.
2. Confirm that the active goal is visible.
3. Walk to the damaged dock.
4. Confirm that the goal changes to complete.
5. Return to the resident and finish the request.
