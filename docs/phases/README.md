# Development phases

These documents divide the game into small development phases. Each phase adds one player-visible mechanic.

Keep the test world small until phase 44. Use one cove, one sea area, one island, and one port. Add more content only after the related mechanic works.

## Phase rules

Each phase must:

- Add one new player action, choice, or consequence.
- Use one or more systems from an earlier phase.
- Have a short completion test.
- State which later features are not part of the phase.
- Keep all completed phases playable.

Map size, more goods, more fish, more residents, and more dialogue are content work. They are not new mechanic phases.
