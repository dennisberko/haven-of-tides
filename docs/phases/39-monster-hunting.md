## Goal

Let the player hunt one sea monster with a special weapon.

## Add

- Add one sea monster at the clue location.
- Give the ship one harpoon action for this encounter.
- Make the harpoon use ammunition.
- Give the monster one clear attack.
- Let the monster damage the ship and injure the crew.
- Give one monster part as cargo after the hunt.

## Use from earlier phases

- Sailing
- Ammunition
- Ship damage
- Crew injuries
- Cargo limit
- Weather
- Story clues

## Complete when

The player can follow the clue, hunt the monster, and return with one monster part.

## Do not add

- More monster types
- Ship module selection
- Harpoon upgrades
- Gear crafting
- A separate combat screen
- A repeatable boss system

## Test

1. Follow the story clue to the monster area.
2. Start the hunt and use the harpoon.
3. Confirm that each shot uses ammunition.
4. Take one monster attack and confirm its existing costs.
5. Defeat the monster.
6. Confirm that the monster part uses cargo space.
