## Goal

Let one resident request improve one relationship.

## Add

- Add one visible relationship value for one named resident.
- Increase it when the player completes that resident's request.
- Show the increase in the request result.
- Add one threshold with one new dialogue scene.
- Save the relationship value.

## Use from earlier phases

- Dialogue
- Resident requests
- Construction
- Resident reactions

## Complete when

A completed request increases one relationship and opens one new dialogue scene.

## Do not add

- Romance
- Gifts
- Relationship decay
- Several relationship currencies
- Daily schedules
- Passive statistic bonuses

## Test

1. Note the resident's relationship value.
2. Accept and complete the resident's request.
3. Confirm that the result shows the increase.
4. Reach the first threshold.
5. Talk to the resident and view the new scene.
6. Load the saved game and confirm that the value remains.
