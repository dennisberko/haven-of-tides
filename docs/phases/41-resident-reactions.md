## Goal

Make one named resident remember an important voyage event.

## Add

- Record one important event from a voyage.
- Give one named resident a reaction to that event.
- Show the reaction when the player next talks to the resident.
- Show the reaction one time.
- Keep the normal dialogue available after the reaction.

## Use from earlier phases

- Dialogue
- Resident requests
- Heat
- Story clues
- Monster hunting

## Complete when

One resident gives different dialogue after one raid, discovery, or monster hunt.

## Do not add

- Relationship points
- Romance
- Opinions for unnamed residents
- A reputation system
- Daily schedules
- Reactions to every player action

## Test

1. Talk to the resident before the selected voyage event.
2. Complete that event and return to the cove.
3. Talk to the resident again.
4. Confirm that the new reaction appears.
5. Start another talk and confirm that normal dialogue returns.
